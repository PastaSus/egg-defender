# Egg Defender — Game Brief

## Core Fantasy

**You are an egg cell, desperately surviving waves of sperm in a frantic, absurd, and hilarious biological bullet heaven.**

One sentence: Survive the swarm by auto-attacking with biological weapons while upgrading your defenses in a roguelite survival arcade game.

## Target Audience

**Primary:** Casual mobile/PC gamers (18-35) who enjoy Vampire Survivors-style games and appreciate humor/absurd themes.

**Secondary:** Roguelite enthusiasts looking for quick 15-20 minute runs with silly biological humor.

**Session length:** 15-25 minutes per run. Quick pick-up-and-play.

## Genre & Core Loop

**Genre:** 2D Horde Survival / Bullet Heaven / Roguelite

**Core Loop:**
1. Start run → Choose weapon loadout [ASSUMPTION: single starting weapon, unlock more via meta-progression]
2. Survive waves → Auto-attack + dodge enemies
3. Collect XP → Level up → Choose upgrades
4. Die or clear wave → Spend currency on permanent upgrades
5. Repeat with harder enemies and new builds

## Gameplay Pillars

1. **Absurd Biological Humor** — Sperm enemies, egg defenses, biological weapons (acid, mucus shields, etc.)
2. **Satisfying Auto-Combat** — Weapons fire automatically, focus on positioning and dodging
3. **Build Variety** — Different weapon combinations create unique run experiences
4. **Quick Runs** — 15-25 minute sessions with meaningful meta-progression

## Core Mechanics

- **Auto-Attack Weapons:** Egg throws, acid sprays, mucus barriers, nucleus beam, etc.
- **Wave System:** Increasing difficulty, enemy variety scales per wave
- **XP & Leveling:** Collect from defeated enemies, choose upgrade at each level
- **Meta-Progression:** Unlock new weapons, starting bonuses, character variants [ASSUMPTION:roguelite-style permanent upgrades]
- **Boss Waves:** Every 5 waves, special boss sperm with unique mechanics

## Comparable Titles

| Game | What We Take | What We Leave |
|---|---|---|
| **Vampire Survivors** | Auto-attack loop, wave escalation, XP/upgrade system | Dark fantasy, complex unlock trees |
| **Brotato** | Arena survival, build diversity | Shop between waves (keep it real-time) |
| **HoloCure** | Humor/absurd theme, polished game feel | IP dependency, complex meta-progression |
| **20 Minutes Till Dawn** | Quick run length, build variety | Manual aiming (keep auto-attack) |

## Differentiators

1. **Biological Theme** — No other horde survivor uses cellular biology as the core aesthetic
2. **Humor-Forward Design** — Silly, absurd tone differentiates from dark/grim competitors
3. **Simplified Meta** — Faster unlocks, less grind than Vampire Survivors
4. **Mobile-First Potential** — Simple controls translate well to touch

## Scope & MVP

**Target Platform:** PC (primary), Mobile (secondary) [ASSUMPTION: PC first, mobile port later]

**Team Size:** Solo developer [ASSUMPTION based on project setup]

**MVP (Minimum Viable Product):**
- 1 playable character (egg cell)
- 4-5 weapon types
- 5 enemy types (different sperm variants)
- Basic wave system (10 waves)
- XP/leveling with 3 upgrade choices
- 1 boss encounter
- Meta-progression (unlock weapons)

**Out of Scope for MVP:**
- Multiple characters
- Complex narrative
- Multiplayer
- Console ports

## Art & Audio Direction

**Art Style:** Cartoon/cellular biology aesthetic. Think "Osmosis Jones meets Vampire Survivors." Bright colors, exaggerated animations, clear silhouette readability.

**Audio:** Upbeat electronic/synth soundtrack. Satisfying squish/splat SFX for biological attacks. Humorous voice lines or sound effects.

## Success Metrics

- Fun in first 30 seconds of gameplay
- Builds feel distinct and powerful
- Runs are replayable (different builds each time)
